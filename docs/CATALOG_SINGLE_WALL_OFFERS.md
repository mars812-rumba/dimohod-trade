# Одноконтурные трубы: исполнения и цены — 2026-11-23

На категории `/catalog/odnokonturnye-truby` подготовлен серверный блок
«Исполнения и цены». Он стоит сразу после короткого введения, перед фильтрами.
Первые два предложения существующего описания оставлены наверху; остальной
текст без переписывания перенесён ниже товаров и пагинации. Обработка касается
этой категории, включая её фильтрованные URL; SEO-подборки и другие категории
сохраняют прежнее описание и расположение блоков.

## Данные и ссылки

`apps/web/lib/catalogSingleWallOffers.ts` выполняет параллельные серверные
`getProducts` для Ø100/115/120/150. Используется существующий публичный источник
каталожных карточек, `cache: no-store`, без новых endpoint или миграций.
Каждый запрос ограничен категорией, видом «труба», одностенным контуром,
диаметром, длиной 1000 мм, AISI 304, внутренней толщиной 0,5 мм и материалом
`stainless` (существующая API-группа нержавеющей стали).

Ответ повторно проверяется на точные параметры, отсутствие наружного диаметра
и наличие выбранного SKU/артикула. При отсутствии совпадения строка пропускается;
другое исполнение семейства не подставляется. Ошибка отдельного запроса не мешает
остальным строкам; без доступных совпадений весь необязательный блок скрыт.

`CatalogSingleWallOffers.tsx` выводит общие параметры один раз, затем обычную
HTML-таблицу с диаметром, ценой за штуку и `<a href>` «Открыть →».
`productSelectionPath` сохраняет артикул выбранного SKU и длину в ссылке.
Цены берутся из `price_rub` выбранного исполнения. Денежное отображение такое же,
как в существующей карточке товара: округление только для показа до целых рублей,
без изменения исходной цены. При отсутствии цены — «Цена по запросу».
Никаких цен и таблиц соответствий SKU в исходниках нет.

## Отображение

Локальный CSS-модуль использует существующие цвета, типографику и оформление
таблиц. Три колонки имеют фиксированные доли ширины, таблица не имеет минимальной
ширины или горизонтального scroll-контейнера. На 360 px одновременно видны цена
и ссылка каждой строки; ссылки имеют высоту не менее 44 px и видимый keyboard focus.
У таблицы есть caption и `scope` у заголовков. Новый блок не добавляет клиентский JS,
обработчики клика или предварительную загрузку карточек.

  отсутствующий диаметр, недоступный API, перенос описания, серверный HTML
  таблицы/ссылок, существующие фильтры, URLs и таблица сэндвичей.
- Production-сборка Next.js и TypeScript прошла. Существующее предупреждение
  Autoprefixer в `AdminCatalogManager.module.css` не связано с доработкой.
- `tools/check_catalog_single_wall_offers_browser.cjs` проверен на отдельной
  сборке с loopback-прокси `tools/product_ready_kits_preview.py`.
  Прокси дополнен только GET выдачи `/api/v1/products`; записи в production,
  админка и отправка форм не используются.
- На реальных публичных данных каждая строка открывает выбранное исполнение:
  `DT-GOLYE-07-00-D100`, `DT-GOLYE-07-00-D115`, `DT-GOLYE-07-00-D120`,
  `DT-GOLYE-07-00-D150`. Сверены SKU ID/артикул, диаметр, длина 1000 мм,
  AISI 304, толщина 0,5 мм, исходная цена API и отображаемая цена карточки.
- Проверены 360/768/1440 px: переполнения нет, цена и ссылка видны одновременно.
  В исходном HTTP HTML присутствуют все строки; ссылки работают без JavaScript.
- Форма фильтров реально отправлена GET-запросом с Ø115 и длиной 500 мм:
  параметры, карточка и фотография соответствуют выбору. В товаре проверено
  переключение фотографий и галереи для 150/350/500/750/1000 мм.
- На категории сэндвичей новый блок отсутствует, прежний блок сохранён.
