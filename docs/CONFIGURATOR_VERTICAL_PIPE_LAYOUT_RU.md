# Раскладка вертикальных труб между перекрытиями

## Цель

Подбирать вертикальные участки дымохода так, чтобы:

- соединения труб не попадали внутрь перекрытий;
- основная высота набиралась метровыми трубами;
- короткая труба использовалась как один компенсационный участок;
- количество коротких труб и соединений было минимальным.

Документ фиксирует расчётную логику конфигуратора. Монтажные ограничения и допустимые зоны соединений должны проверяться по проекту и инструкции выбранной дымоходной системы.

## Подтверждённые монтажные длины

| Элемент | Номинальная длина | Полезная монтажная длина |
| --- | ---: | ---: |
| Шибер | — | 150 мм |
| Опорная заглушка | — | 40 мм |
| Труба 1000 мм | 1000 мм | 950 мм |
| Труба 500 мм | 500 мм | 450 мм |
| Труба 250 мм | 250 мм | 200 мм |

Каждая труба входит в соседний элемент на 50 мм. Поэтому полезная длина трубы равна:

```text
полезная длина = номинальная длина − 50 мм
```

Вычет 50 мм применяется к одному соединению только один раз. Для шибера и опорной заглушки выше уже указаны полезные монтажные длины; повторно уменьшать их не нужно.

## Обозначения первого этажа

```text
H1  — высота первого этажа;
l1  — высота от пола до патрубка печи;
l2  — полезная длина разгонной одноконтурной трубы;
hп  — толщина перекрытия;
H12 — выход собранной трубы над полом второго этажа.
```

Перед расчётом обязательно зафиксировать способ измерения `H1`:

1. от пола первого этажа до низа перекрытия; или
2. от пола первого этажа до пола второго этажа.

Смешивать эти два способа нельзя.

## Базовая сборка первого этажа

Для подтверждённой последовательности:

```text
патрубок печи
→ одноконтурная труба 1000 мм
→ шибер
→ опорная заглушка
→ сэндвич-труба 1000 мм
```

полезная высота элементов над патрубком составляет:

```text
950 + 150 + 40 + 950 = 2090 мм
```

Абсолютная отметка верхнего края первой сэндвич-трубы:

```text
Z = l1 + 2090 мм
```

## Расчёт выхода на второй этаж

Если `H1` измеряется от пола первого этажа до низа перекрытия:

```text
H12 = l1 + 2090 − H1 − hп
```

Если `H1` измеряется от пола первого этажа до пола второго этажа и уже включает перекрытие:

```text
H12 = l1 + 2090 − H1
```

Интерпретация результата:

- `H12 > 0` — труба вышла над полом второго этажа на `H12` мм;
- `H12 = 0` — край трубы оказался на уровне пола второго этажа;
- `H12 < 0` — до уровня пола второго этажа не хватает `|H12|` мм.

## Логика следующих этажей

`H12` переносится в расчёт второго этажа как фактическая начальная отметка. Конфигуратор должен:

1. определить положение следующего перекрытия;
2. перебрать доступные компенсационные трубы по их полезной длине;
3. после компенсатора добавить максимально возможное количество метровых труб по 950 мм полезной длины;
4. проверить, что ни одно соединение не оказалось внутри перекрытия;
5. выбрать вариант с минимальным количеством коротких труб и соединений.

Правило `компенсатор = H2 / 3` не является обязательной формулой. Нижняя треть этажа может использоваться как предпочтительная зона размещения доступного соединения, но длина компенсатора должна вычисляться по фактическим отметкам и доступным SKU.

Та же логика повторяется для третьего, четвёртого этажа и чердака: результат предыдущего участка становится начальной отметкой следующего.

## Обязательное правило реализации

Расчёт и спецификация должны использовать полезные монтажные длины. Номинальные длины `1000`, `500` и `250` мм используются для названий и выбора SKU, но не для сложения фактической высоты собранного дымохода.
