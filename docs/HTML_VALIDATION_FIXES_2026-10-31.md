# Исправления HTML по отчёту владельца — 31.10.2026

## Область

Подтверждённые замечания из присланного фрагмента W3C-отчёта: потоковые метаданные вне head, aria-label на generic div, отзывы article без заголовков, избыточный region на именованном section-карусели. Это не обещание нулевых сообщений валидатора на всём сайте: полный исходный отчёт не предоставлен.

## Изменения

- `next.config.ts`: `htmlLimitedBots: /.*/` отключает streaming metadata для всех User-Agent. Используется штатная настройка Next.js 15.5.20, без второго комплекта ручных метатегов. Значения title/description/canonical/OG/robots не менялись. Возможен компромисс по времени первого байта при ожидании метаданных на динамических страницах; полевой выигрыш/ухудшение не заявляется.
- SiteHeader: именованная группа правовых ссылок. ProductGalleryPreview, ProductExperience и CatalogProductCard: именованные группы характеристик и миниатюр. HomeWorksShowcase: группы выбора объекта и фотографий. Обёртки с реальной группировкой содержимого получили role=group; интерактивные элементы и обработчики сохранены.
- Главная: рейтинг обёрнут в именованную группу; имена авторов стали h3 внутри article отзывов. CSS сохраняет прежние 15 px, жирность 700, межстрочный интервал и нулевой margin.
- HomeHeroCarousel: убрана избыточная явная роль region с именованного section. Имя, aria-roledescription, управление и анимация сохранены.
- Исправлен тот же случай рейтинга в обеих посадочных HomeScenarioLanding и BanyaScenarioLanding; у индикатора шага HomeQuickEstimate удалена лишняя подпись generic div, поскольку номер шага уже есть видимым текстом внутри него.
- Дополнительная проверка собранной главной через validator.w3.org/nu выявила замечания вне присланного фрагмента: бейдж Яндекс-рейтинга на span получил роль группы; контейнер h3 в карточках маршрутов изменён со span на div; три article в блоке проверки комплекта получили h3 вместо strong с сохранением размера шрифта. Тексты не менялись.

Навыки fixing-metadata и fixing-accessibility определили точечный подход: штатный Metadata API, отсутствие дублирования, осмысленные группы и заголовки без изменения содержимого и дизайна. ui-skills CLI подтвердил применимость fixing-accessibility.

Не удалялись карта iframe, рабочее CSS-свойство paint-order и React-форма записи void-тегов (`img .../>`). Информационное сообщение про trailing slash не равно ошибке. CSS/JS не оптимизировались в рамках этой задачи. Производственные сервисы не перезапускались, deploy/commit/push не выполнялись.

## Проверки

- Финальная изолированная production-сборка `.next-html-final-20261031-check` завершилась успешно, включая TypeScript и 74 страницы. Прежние предупреждения autoprefixer в AdminCatalogManager.module.css/globals.css не относятся к этой задаче. Автоматические изменения next-env.d.ts/tsconfig.json от изолированной сборки отменены точечно.
- Финальные HTTP-проверки пяти страниц (`/`, категория сэндвич-труб, труба 110 мм, гайд про баню, `/solutions/banya`) с четырьмя User-Agent (браузер, Googlebot, YandexBot, Validator.nu): HTTP 200; по одному title/description/canonical/OG title/Twitter card внутри head; нет aria-label на generic div/span без роли в этой выборке.
- 53 профильных Node-теста (новые htmlValidation, indexingContract, product*) прошли.
- Расширенный запуск home* + product* + indexingContract + htmlValidation: 111 прошли из 113, 2 старых несвязанных падения в homeScenarioLanding.test.mjs (ожидания «Ориентировочная стоимость» и «Гарантия от 5 лет»). Падения наблюдались до правки роли рейтинга HomeScenarioLanding; тексты посадочной, SolutionTrustSections.tsx и этот тест не изменялись. Не исправлялись, чтобы не менять чужие тексты/задачи.
- Chromium 390/1440 px на локальной сборке: один title в head, пять h3 авторов отзывов, отсутствие generic div с aria-label на главной, нет горизонтального скролла и ошибок JavaScript. Мобильный блок отзывов визуально просмотрен.
- Промежуточный локальный замер главной: медиана времени до заголовков ответа 90 мс на предыдущей сборке и 77,5 мс на исправленной (по 4 последовательных запроса, первые холоднее). Это не полевые CWV и не доказательство ускорения; заметного регресса в этом коротком опыте не обнаружено.
- Исправленный HTML главной отправлен напрямую в `https://validator.w3.org/nu/?out=json`: HTTP 200. Ошибки HTML и предупреждения отсутствуют; остаётся ровно одна ошибка встроенного CSS-проверяющего `paint-order: Property doesn't exist`. Это существующее CSS-свойство, поэтому визуальный эффект не удалялся ради устаревшего CSS-профиля проверяющего. Информационные trailing-slash сообщения React остаются.
- Проверка финальной главной в Chromium 390/1440 px: три h3 маршрутов имеют div-контейнеры, пять h3 авторов, отсутствуют горизонтальный скролл и ошибки JavaScript. Скриншот маршрутов просмотрен.

## Источник настройки

https://nextjs.org/docs/app/api-reference/config/next-config-js/htmlLimitedBots — штатный способ полностью отключить streaming metadata. Результат должен перепроверяться на публичном URL после отдельной публикации владельцем. Реальная обработка поисковыми роботами и карточки соцсетей после публикации ещё не проверены.
