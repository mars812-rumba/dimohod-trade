# Добавление хомута в смету — 29.10.2026

Причина: редактор переносил пару диаметров трубы (например, 180/280) на все найденные товары. SKU широкого хомута имеет один диаметр 280 и отсеивался перед добавлением.

`estimatePickerVariants` в `clampVariants.ts` теперь для широкого/силового хомута выбирает точные SKU по `outer ?? diameter`. Для самой трубы сравнение d/D остаётся прежним. При замене существующего хомута его собственный диаметр используется как есть; добавления 100 мм повторно нет. Если нужного диаметра в каталоге нет, список пустой — ближайший размер/Ø100 не подставляется.

Это правка редактора, не автоматическое добавление широкого хомута в расчёт и не изменение каталога. Сохранённые сметы, цены и количество не переписываются.

Проверки: 11 модульных тестов подбора и связанных регрессий; сборка Next.js. Браузер на реальных публичных SKU проверил добавление Ø280 из контекста 180/280, последующую замену, сохранение количества/примечания и отказ при отсутствующем Ø400. Ошибок JavaScript нет. API-записи были подменены; рабочие заявки не менялись.
