# Скидка в редакторе сметы — 28.10.2026

- «Дать скидку» раскрывает процент (0–100, до двух знаков после запятой). Предпросмотр пересчитывается сразу; сохранение выполняется существующими кнопками сохранения сметы / формирования PDF.
- Процент и флаг хранятся в `estimate.discount_enabled` и `estimate.discount_percent`. Сервер вычисляет `discount_amount_rub` и `total_after_discount_rub` из суммы позиций, округляя скидку до копеек (`Decimal`, `ROUND_HALF_UP`). Цены отдельных строк и исходная сумма не меняются.
- Используется защищённый PATCH `/leads/{lead_id}/manager/document` с проверкой редакции. Новая скидка увеличивает редакцию; снимки и PDF привязаны к ней. При изменении строк скидка пересчитывается существующим серверным пересчётом.
- PDF сметы содержит исходную сумму, процент/сумму скидки и итог. Без включённой скидки дополнительных строк нет. Спецификация без цен остаётся без цен и скидки.
- В списке клиентов отображается итог с учётом скидки. Старые сметы без новых полей работают как прежде.
- Неизвестные цены не включаются в базу скидки; предупреждение сохраняется. Исправлена пустая таблица замеров, мешавшая формированию PDF для смет без замеров.
- Запросы публичного создания заявки не принимают поля скидки. Новое управление использует существующий доступ администратора/менеджера к смете.

Проверки: серверные тесты документа/скидок/заявок, клиентские расчёты и PDF-структура, сборка Next.js; браузерные проверки выполняются с полностью подменённым API, без изменения реальных заявок.
