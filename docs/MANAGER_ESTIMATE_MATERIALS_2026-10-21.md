# Материалы внутренней и наружной трубы в редакторе сметы

## Изменение

По запросу владельца расширен только редактор сметы `ManagerEstimateCard`:

- В строках труб и в окне добавления/замены SKU доступны отдельные списки «Внутренняя труба» и «Наружная труба».
- «Оцинковка» определяется по существующему полю материала, а не по отсутствию AISI. Пустые данные остаются неизвестными. Для оцинкованного материала устаревшее заполнение AISI не превращает его в нержавейку.
- Для сэндвича различаются толщины внутренней и наружной трубы. Наружная толщина доступна, если она встречается в данных семейства; неизвестная толщина не придумывается.
- Обычная одностенная труба не получает лишние наружные поля.
- Списки строятся из реальных SKU: сначала внутренняя и наружная труба, затем толщины и длина. Это позволяет выбрать наружное исполнение, даже если у него отличается заполненность внутренней толщины в старых записях каталога.
- При смене исполнения сохраняются предшествующие параметры, по возможности длина и остальные характеристики. Сохраняется конкретный существующий SKU, не произвольная комбинация параметров.
- В строках по-прежнему используется существующее автосохранение после действия пользователя. В окне выбора сохранение происходит только кнопкой добавления/замены; при открытии окна сохраняется исходный SKU редактируемой позиции.
- Артикул, цена и характеристики берутся из выбранного SKU существующим серверным обработчиком. Количество и примечание передаются без изменения.

Данные каталога, модель Product/SKU, правила совместимости, расчёт дымохода и backend API не менялись. Массовых переносов стали из внутренней трубы в наружную нет. Сохранённые клиентские сметы при разработке не редактировались.

## Проверки

- Production-сборка Next.js, включая проверку TypeScript: успешно. Существующие предупреждения Autoprefixer в глобальном CSS и админке каталога не относятся к изменению.
- 15 целевых тестов: успешно. Покрыты внутренняя/наружная оцинковка, отсутствующие параметры, наружная толщина, сохранение длины, недоступные комбинации, идентичный выбор без смены SKU, неизменность исходных данных и одностенные изделия.
- Read-only проверка публичного API: у семейства `sendvich-truba` взяты 132 исполнения Ø110/210; проверены 2 172 перехода по доступным значениям. Каждый результат — существующий SKU, предшествующие параметры сохраняются.
- Chromium/Playwright на локальной production-сборке: добавление и замена SKU, переключение 304/430/оцинковки, артикул и цена, сохранение количества/примечания, отсутствие записи при открытии и при редактировании неподтверждённого окна, отказ сохранения HTTP 409 и повторная попытка.
- Все семь запросов изменения в браузерном сценарии перехвачены и обслужены локальной заглушкой; данные клиента синтетические. Реальных API-записей сметы, писем или заказов не создавали.
- Строка проверена на 360/390/430/1440 px, окно выбора — 390/1440 px. Горизонтального переполнения и ошибок JavaScript нет. Для скриншотов тестовой строки миниатюра отсутствует намеренно: metadata-заглушка возвращает `image: null`.
- Механическая проверка Impeccable: `[]`. Сохранены существующие стили и нативные select с доступными подписями, без новых зависимостей или редизайна.

Проверка с перехватом не является проверкой реальной записи production-сметы или доставки PDF. Эти операции не выполнялись. Commit, push, deploy и перезапуски production не выполнялись.

## Файлы

### Уточнение владельца: все сэндвич-изделия, не только трубы

После проверки скриншотов тройника и заглушки устранён ограничивающий показ `isPipe`: общий выбор материалов теперь доступен в строках всех изделий с категорией `sendvich-*` или явным сэндвич-/двустенным контуром. Покрыты также опорные площадки с соответствующим контуром, даже если название категории не начинается с `sendvich-`.

При смене материала сохраняются d/D, угол, толщина утепления и дополнительные размеры/исполнение из атрибутов. Длина не выводится, если у всех вариантов отсутствует. Эти же ограничения действуют в общем интерфейсе выбора SKU; фланцы сохраняют существующий отдельный выбор размера. Новые варианты каталога и цены не создаются.

Проверки уточнения:

- 18 целевых тестов и TypeScript: успешно; локальная Next.js-компиляция изменённого редактора успешна. Отдельная production-сборка после этого уточнения не запускалась.
- Read-only проверены все 13 найденных сэндвич-семейств, включая трубы, отводы 45°/90°, тройники 45°/90°, четверник, оба шибера, заглушку, опорную площадку и три оголовка. Проверены 4 280 переходов на выборках одной геометрии из каждого семейства; все результаты принадлежат исходным вариантам.
- В браузере проверены строки семи семейств: тройник, заглушка, отвод, четверник, шибер, дефлектор и труба. Проверены наличие четырёх полей материалов/толщин, отсутствие ненужной длины у фасонных изделий, артикул/цена и сохранение геометрии/количества/примечания после выбора. Все семь изменений обслуживались заглушкой, не рабочей CRM.
- Мобильные ширины 360/390/430 px и десктоп 1440 px: без горизонтального переполнения; ошибок JavaScript нет. Снимки строки тройника визуально проверены. Impeccable detector: `[]`.
- Оцинковка предлагается только там, где она есть среди доступных SKU. Для части оголовков наружная оцинковка не найдена, искусственно не добавлялась.
