# Номер КП и две PDF-формы — 23.10.2026

## Реализовано

В административном редакторе перед «Сформировать PDF» добавлен подписанный инпут «Номер КП»
(до 80 символов). Номер сохраняется кнопкой сохранения сметы и автоматически перед генерацией.
Изменение номера создаёт следующую редакцию; повторное сохранение того же номера редакцию не увеличивает.
В старых сметах поле может отсутствовать — миграция существующих заявок не нужна.

Одна генерация сохраняет два файла из одной редакции и возвращает две отдельные кнопки скачивания:

1. Обычная смета: существующий PDF без изменения шаблона, с сохранёнными ценами и фотографиями, если они доступны.
2. Спецификация: отдельный A4-шаблон по присланному образцу, без цен, сумм и фотографий.
   В шапке номер КП, покупатель и контакт; поля начала/конца изготовления, готовности и диаметра оставлены пустыми.
   Таблица: номер строки, наименование с характеристиками, количество, единица «шт».
   Внизу «Со спецификацией согласен», места для подписи, расшифровки и даты.

Во вторую форму не передаются внутренние заметки, предупреждения, удалённые позиции и суммы.
При переносе на следующие страницы повторяется шапка таблицы; блок согласования не разрывается.
Автоматической загрузки нескольких файлов нет: пользователь выбирает файл отдельной кнопкой,
что подходит для мобильного браузера. Ссылки на сформированные Blob-файлы скрываются при изменении номера или редакции.

## Хранение и защита

- `PATCH /api/v1/leads/{lead_id}/manager/document` — сохранение `quotationNumber` с проверкой редакции и существующей авторизации.
- `POST /api/v1/leads/{lead_id}/manager/pdf` — существующий `pdf_file` и необязательный `specification_file`.
- Оба входных файла проверяются на PDF-тип, сигнатуру и ограничение 12 МиБ каждый до записи документов.
- В каталоге заявки сохраняются `estimate-r{revision}.pdf`, `specification-r{revision}.pdf` и снимок JSON с номером КП.
- `GET .../manager/pdf` сохраняет прежнее поведение; `?document=specification` выдаёт спецификацию текущей редакции под тем же доступом.
- Спецификация устаревшей редакции не выдаётся как актуальная. Произвольный путь через параметр документа передать нельзя.
- Старый запрос загрузки только обычного PDF без номера КП остаётся поддержанным.
