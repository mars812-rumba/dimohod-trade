# Дымоход Трейд: задачи для роста органических заявок

Дата: 2026-10-03. Статус: первый этап подготовлен локально, не опубликован.
Отчёт и ограничения: `docs/ORGANIC_GROWTH_S01_S05_REPORT_2026-10-03.md`.
S01 — базовая линия с ограничениями данных; S02 — проверен пилот из семи запросов;
S03 — частично, ждёт реальных расчётов и прав на фото;
S04 — шаблон подготовлен; S05 — основные правки подготовлены, реальные примеры ещё не добавлены.
Участники: владелец — исходные данные и проверка; Codex — исследования, подготовка и реализация.

## 1. Цель и принятые решения

Привлекать людей, выбирающих конкретный дымоход или комплект, и доводить их до расчёта и заявки.
Оценивать результат по органическим заявкам и полезным переходам, а не по количеству URL в индексе.

Первый пилот: три усиленные коммерческие страницы, два обновлённых гайда и два новых модельных материала.
Материалы связываются с реальным каталогом, расчётом, схемой и BOM.

- Категории обслуживают поиск товара и цены; сценарные страницы — покупку комплекта для задачи.
- Гайды помогают принять решение: выбрать исходные данные, понять состав и стоимость комплекта.
- Формат страницы окончательно выбирается после проверки поисковой выдачи.
- Реальных персональных авторов и страницы авторов пока откладываем. Не выдумываем экспертов.
- Источники, реальные даты обновления и проверяемые данные нужны уже в пилоте.
- Активные товарные страницы не скрываем только из-за отсутствия фотографий.
- Публикация — через отдельное действие владельца в Telegram-боте. Codex не выполняет commit,
  push, production deploy и перезапуск production-сервисов.

Не обещаем позиции, сроки роста или цитирование LLM. Причина низкого трафика не установлена
одним числом индексируемых страниц; проверяем спрос, видимость, соответствие страниц запросам и конверсию.

## 13. Задача S10: оценить пилот и выбрать следующий цикл

- [ ] Выполнено.

Отсчёт вести от фактической индексации, а не только даты публикации.
Раз в неделю записывать показатели; первую содержательную оценку провести через 4–8 недель.
Это окно наблюдения, не гарантия получения трафика.

| Наблюдение | Следующее действие |
| --- | --- |
| Страница не индексируется | Проверить доступность, canonical, robots, sitemap и отчёт Вебмастера |
| Индексируется, но показов нет | Проверить спрос, соответствие формата выдаче и внутренние ссылки |
| Показы есть, позиции слабые | Сравнить полезность и полноту ответа с результатами по тому же запросу |
| Позиции есть, кликов мало | Проверить сниппет и интент; учитывать регион, устройства и малый объём данных |
| Клики есть, расчётов мало | Проверить релевантность примера, ясность CTA и работу калькулятора |
| Расчёты есть, заявок мало | Проверить форму, ошибки, обещания пользователю и успешную отправку |
| Две страницы получают один кластер | Проверить, действительно ли они конкурируют; уточнить роли и ссылки |

Сравнивать одинаковые окна времени и поисковые источники; учитывать сезонность и задержки данных.
Не менять title каждые несколько дней. Масштабировать темы, дающие полезные входы и заявки.

## 14. Рекомендуемый порядок работ

1. S01–S03: исходные метрики, проверка выдачи и сбор фактов.

3. S06: первым обновить гайд о комплекте для печи.
