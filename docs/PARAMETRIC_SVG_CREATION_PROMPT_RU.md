# Дымоход Трейд: канонический промпт параметрических SVG-схем

Это основной шаблон для создания и доработки размерных SVG-схем каталога. Его нужно читать до изменения `DimensionScheme` или добавления нового форм-фактора.

Если при работе над изделием появляется общее требование для всех схем, сначала обновить этот документ, затем реализацию. Особенности только одного форм-фактора следует оставлять в его геометрии.

## Как использовать

1. Заполнить секцию `input` и приложить фотографии реального изделия.
2. Главное фото использовать как источник геометрии, дополнительные виды — для проверки соединений.
3. Создавать одну геометрию на форм-фактор, а не отдельный SVG на каждый SKU.
4. Проверить соединения, симметрию, мобильный вид, динамические значения и production-сборку.

## Каноническое правило

Один форм-фактор соответствует одной статичной SVG-геометрии. Значения `L`, `D`, `d`, `S`, толщина утепления, марка стали и материал подставляются из выбранного SKU только в текстовые элементы и метаданные. Отдельные SVG-файлы для разных диаметров, толщин и марок стали не создаются.
