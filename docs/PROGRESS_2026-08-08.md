# Привязка фотографий SKU по диаметру и длинам — 2026-08-08

## Задача

Расширена существующая привязка фотографии SKU к диаметру. При загрузке одного фото администратор
может одновременно выбрать:

- ограничение «Только для выбранного диаметра d/D»;
- одну или несколько длин, для которых подходит это фото.

Например, фото, загруженное у SKU `D200 × L500`, можно назначить диаметру `D200` и длинам
`500, 1000 мм`. Оно будет использоваться у исполнений `D200 × L500` и `D200 × L1000`, но не у
других диаметров или длин.

## Правила применения

Ограничения диаметра и длины работают как пересечение:

| Диаметр | Выбранные длины | Где показывается фото |
|---|---|---|
| Не ограничен | 500, 1000 мм | Все диаметры текущего материала с длиной 500 или 1000 мм |
| Ограничен | 500, 1000 мм | Только выбранный d/D с длиной 500 или 1000 мм |

- варианты длины берутся из активных SKU текущего товарного семейства и материала;
- текущая длина SKU отмечается автоматически после выбора файла;
- для изделия с длиной нельзя сохранить фото, не выбрав хотя бы одну длину;
- для изделия без параметра длины блок выбора длин не показывается;
- если одновременно подходят несколько фото, сначала выбирается фото конкретного диаметра, затем
  самое новое;
- старые фото без поля `lengths_mm` продолжают применяться к длине SKU, у которого они сохранены.

## Хранение данных

У записи фото в существующем JSON-массиве `sku_media` добавлено поле:

```json
{
  "url": "/media/catalog/skus/example/general.jpg",
  "role": "general",
  "diameter_specific": true,
  "lengths_mm": [500, 1000]
}
```

Новая таблица и миграция базы данных не требуются. Один файл хранится один раз; выбранные длины
описывают область его применения.
