# Пилот: исполнения и цены сэндвич-труб

## Объём

Только базовая `/catalog/sendvich-truby`, без параметров и SEO-подборок.
Добавлено сравнение до шести конкретных исполнений между фильтрами и
существующей карточкой семейства. Фильтры, карточка, корзина и описание сохранены.

Примеры выбираются среди реально доступных диаметров категории.
Приоритет: 115/215, 120/220, 150/250, 180/280, 200/300, 250/350 мм;
при отсутствии размера используется следующий существующий. Это редакционные
примеры, **не рейтинг продаж и не рекомендация совместимости**.

Материалы контуров и длина соответствуют начальному выбору категории.
Каждая строка запрашивается через существующий `getProducts` с реальными
фильтрами, без кеширования цен. Внутренняя и наружная труба показаны отдельно.
Ссылка включает выбранный артикул, а не ведёт на произвольное исполнение.
Цена выводится с копейками, если они есть; отсутствие цены не заменяется нулём.
Пояснение отделяет цену одной трубы от стоимости комплекта.

«Помочь с подбором» ведёт к существующей форме `/#send-materials`.
Новой формы и новой системы заявок нет. Название исходной категории этим
переходом отдельно в заявку не передаётся. Фото и документы необязательны.

в новый пилот. URL, canonical, robots, sitemap, цены в БД, характеристики,
совместимость и алгоритмы расчётов не менялись.

- 23 теста `catalog*.test.mjs` прошли, включая три новых.
- Проверены ширины 360, 390, 768 и 1280 px: горизонтального переполнения страницы нет.
- На телефоне таблица имеет собственную горизонтальную прокрутку и пояснение;
  клавиатурная прокрутка и видимый фокус проверены.
- Шесть строк и ссылки видимы без JavaScript.
- Цена первой строки сверена с API выбранного артикула; переход к нему работает.
- Переход к существующей форме проверен, заявки не отправлялись.
- Фильтр диаметра работает; на фильтрованной странице пилот скрыт.

- Ошибок JavaScript в проверенном сценарии нет.
- Механический UI-detector не нашёл нарушений в изменённых компонентах.
- `git diff --check` прошёл.

UI-навыки использованы для сохранения существующего оформления, семантической
таблицы, клавиатурного доступа и ограниченной мобильной прокрутки.
SEO-навык проекта ограничил подписи фактическими параметрами API;
монтажных и пожарных обещаний не добавлялось.

## Ограничения

Шесть параллельных запросов добавляют серверную работу только базовой категории.
Пилот не считается доказательством будущего роста позиций: результат следует
оценивать после публикации и переобхода по небрендовым показам и переходам.
При сбое запроса отдельный пример пропускается; при полном сбое остаётся
пояснение и переход к помощи, основная категория не исчезает.

Ничего не публиковалось, переобход не отправлялся. Следующие изменения
других категорий требуют отдельного решения.
