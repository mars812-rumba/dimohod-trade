# Редактура статей «Дымоход Трейд»

Настроено 2026-11-24 по запросу владельца. Правила относятся только к этому
проекту и задачам подготовки/редактирования статей; публичные страницы и
серверный генератор SEO в этой задаче не менялись.

## Подключённые навыки

- `skills/dimohod-tone-of-voice/SKILL.md` — профиль бренда: опытный консультант,
  спокойное обращение на «вы», понятная логика выбора, действия покупателя,
  реальные примеры только при наличии подтверждений. Это стартовая редакционная
  настройка по согласованному образу, а не анализ личного стиля владельца.
- `skills/humanizer/SKILL.md` — upstream Humanizer 4.0.0, финальная вычитка
  повторов, пустых вступлений и машинных конструкций. Для русскоязычных статей
  действуют уточнения ToV: сохранять уместное тире, кавычки, единицы и ограничения;
  не переносить английские запреты буквально.
- `skills/chimney-product-seo/SKILL.md` — существующие правила доказательности
  технических утверждений. Они применяются к фактам статьи, но не навязывают
  статье структуру товарной карточки.

Маршрутизация добавлена в корневой `AGENTS.md`. В следующих задачах агент
прочитает проектный ToV, а затем Humanizer. Глобальные скиллы и настройки других
проектов не менялись. Сами скиллы не подключают новые внешние сервисы и не
отправляют тексты в отдельный сервис «очеловечивания».

## Как заказывать следующие тексты

Например: «Подготовь черновик статьи для покупателя, который выбирает
маршрут дымохода. Используй наш ToV и Humanizer. Отдельно укажи, какие факты
ещё нужно подтвердить». Для вычитки достаточно дать текст или путь к файлу.

После правок владельца уточнять профиль на конкретных примерах. Не добавлять
новые универсальные запреты по одному замечанию. Хороший результат оценивается
понятностью, пользой и точностью; процент «человечности» и прохождение
AI-детекторов не используются как критерии.
