## Сжатие и проверки

Оба WebP имеют размер 1254×1254 пикселя. Сжатие выполнено существующим
`sharp`: WebP quality 82, effort 6. Обрезка, масштабирование, удаление фона
и перерисовка не применялись.

- Roof: 153 217 → 88 240 байт, уменьшение примерно на 42%.
- Wall: 267 009 → 178 972 байта, уменьшение примерно на 33%.

Проверены идентичность копий исходникам, формат, размеры и полное
декодирование WebP. Изображения просмотрены после конвертации.

## Для следующей задачи

Владелец пришлёт отдельное задание на реализацию карточки. Текущая матрица:
Roof 4m, Roof 6m, Wall 3m, Wall 6m; внутри каждой карточки планируется выбор
диаметра 115 / 120 / 150 мм. Roof 4m — новое название прежнего Roof 3m;
согласованный состав из-за переименования не меняется.

Макет служит визуальным ориентиром, а не источником состава, цен, сроков
отгрузки, наличия или технических характеристик. Составы брать из актуальных
согласованных сохранённых смет, а не из примерной таблицы на макете или
прежних аналитических BOM. Титульные изображения — иллюстрации маршрутов,
не монтажные инструкции и не доказательство точной комплектации.
